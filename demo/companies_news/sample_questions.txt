### Q1.1: Filter by sector
**Question:** "List all companies in the Artificial Intelligence sector"
**Expected:** Query companies.csv, filter by sector

### Q1.2: Filter by location

## Performance Notes

⚠️ **Web Search + LLM is SLOW**
- Use LIMIT to reduce number of searches
- Start with LIMIT 2 or 3 for testing

✅ **Good practice:**
```sparql
{
    SELECT ?company WHERE {
        # CSV query
    }
    LIMIT 3  # ← CRITICAL for performance
}
# Web search + LLM for only 3 companies
```

❌ **Bad practice:**
```sparql
SELECT ?company ?news WHERE {
    # Gets all 15 companies
    BIND(ggf:SLM-CSV(...) AS ?g)
    GRAPH ?g { ?row ex:company_name ?company . }

    # 15 web searches! Very slow!
    BIND(ggf:SLM-WEBSEARCH(?company) AS ?web)
}
```
